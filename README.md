## 1. Cybersecurity Analyst

A Cybersecurity Analyst protects an organization's computer systems and sensitive information.

*Responsibilities:*
- Monitor security activities
- Identify potential threats
- Investigate security incidents
- Analyse vulnerabilities
- Recommend security improvements

*Skills:* Network security, threat detection, and security monitoring.

## 2. SOC Analyst

A SOC Analyst monitors security alerts and investigates suspicious activities.

*Responsibilities:*
- Monitor security alerts
- Analyse network traffic
- Investigate potential attacks
- Identify security incidents
- Prepare security reports

*Skills:* SIEM tools, log analysis, networking, and incident response.

## 3. Ethical Hacker

An Ethical Hacker identifies security weaknesses with proper authorization.

*Responsibilities:*
- Perform authorized security testing
- Identify system vulnerabilities
- Test network security
- Analyse security weaknesses
- Prepare vulnerability reports

*Skills:* Linux, networking, penetration testing, and web security.

## 4. Penetration Tester

A Penetration Tester evaluates the security of websites, applications, and networks through controlled testing.

*Responsibilities:*
- Conduct penetration tests
- Identify vulnerabilities
- Test security configurations
- Document findings
- Recommend improvements

*Skills:* Ethical hacking, vulnerability assessment, and security testing.

## 5. Network Security Engineer

A Network Security Engineer protects computer networks from unauthorized access and cyber threats.

*Responsibilities:*
- Configure firewalls
- Monitor network activities
- Manage VPN connections
- Identify network vulnerabilities
- Improve network protection

*Skills:* Networking, firewall management, and network monitoring.

## 6. Cloud Security Engineer

Cloud Security Engineers protect cloud infrastructure, applications, and digital information.

*Responsibilities:*
- Secure cloud environments
- Manage access permissions
- Monitor cloud security risks
- Protect sensitive information
- Implement security policies

*Skills:* Cloud platforms, identity management, and encryption.

## 7. Digital Forensics Analyst

A Digital Forensics Analyst investigates digital devices and collects evidence related to cyber incidents.

*Responsibilities:*
- Examine digital evidence
- Investigate security incidents
- Analyse system activities
- Recover relevant digital information
- Prepare investigation reports

*Skills:* Digital forensics, operating systems, and analytical thinking.

## 8. Application Security Engineer

An Application Security Engineer helps protect websites, software, and applications.

*Responsibilities:*
- Identify application vulnerabilities
- Review application security
- Perform security testing
- Support secure development
- Recommend improvements

*Skills:* Web security, secure coding, and application testing.

## 9. Information Security Analyst

An Information Security Analyst helps organizations protect confidential information and manage security risks.

*Responsibilities:*
- Assess security risks
- Develop security policies
- Monitor information protection
- Support compliance activities
- Improve organizational security

*Skills:* Risk management, information security, and security policies.

## 10. Incident Response Specialist

An Incident Response Specialist helps organizations investigate and manage cybersecurity incidents.

*Responsibilities:*
- Identify security incidents
- Investigate suspicious activities
- Contain security threats
- Support recovery operations
- Document incident findings

*Skills:* Threat analysis, incident response, and security monitoring.
